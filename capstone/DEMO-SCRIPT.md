# Demo recording script (3–5 min, one take, live)

Record the browser and your voice (macOS Cmd+Shift+5, Windows Win+Alt+R). No slides. Open https://weekly-review-coach.vercel.app in a fresh tab first, zoom to 90%.

| Time | Do | Say (in your words) |
|---|---|---|
| 0:00 | Show the page and the side panel files. Open `week-05.md` for a few seconds. | "This is my Weekly Review Coach. It reviews my internship week, and it only knows my own notes." |
| 0:20 | Point at the **Demo model** badge. | "Right now it runs a demo model, I'll come back to that." |
| 0:30 | Click **Start my weekly review**. Point at each tool card as it moves through its states. | "It lists my files, reads my notes and assignments, and checks my live site. Each step shows what it's doing and why." |
| 1:15 | Scroll the review. Point at a source chip on a Finished item. | "Every finished item cites the note it came from, so I can check it." |
| 1:45 | **Design decision.** Point at the plan card with Approve. | "A design decision: the agent is read-only, and the plan is only a proposal until I approve it. I didn't want a tool that acts for me, I wanted one that makes me reflect." Click **Approve**. |
| 2:30 | Open **Sabotage → Connection drops mid-stream**, ask again, then click **Retry**. | "When it breaks, it says what broke and keeps my message. Retry sends one request, even on a double click." |
| 3:20 | **Limitation.** Point at the Demo model badge again. | "The honest limitation: the live site has no API key yet, so this is a scripted demo model. The tools run for real, but my six behaviour evals haven't been proven on Claude itself. That's the next step." |
| 4:00 | Stop. | "Code and README are linked in the description." |

After: upload (YouTube unlisted or Loom), paste the link at the top of `capstone/README.md`.
